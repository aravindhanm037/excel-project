# 📊 Indian Retail Sales Analysis using Power BI

## 📌 Project Overview
This project focuses on analyzing Indian retail sales data using Microsoft Excel and Power BI. The main objective is to understand sales performance, profitability, customer behavior, and regional business performance through data analysis and visualization.

## 🎯 Project Objectives
- Analyze total sales and total profit.
- Identify top-performing products and categories.
- Understand monthly sales trends.
- Analyze sales performance across Indian states and cities.
- Identify popular payment methods.
- Calculate profit margin and average order value.
- Build an interactive Power BI dashboard.

## 📁 Dataset Information
- **Dataset Name:** Indian Retail Sales Dataset
- **Total Records:** 500 Rows
- **Total Columns:** 18
- **File Format:** Excel (.xlsx)
- **Domain:** Retail Sales and Business Analytics

## 📋 Excel Workbook Sheets
1. **Sales_Data** – Contains retail sales transaction records.
2. **Data_Dictionary** – Explains dataset columns and their meanings.
3. **Project_Guide** – Contains project instructions and analysis objectives.
